# Project Title

Technical Task For Health Assured.

## Description

To create a single page application displaying different resources grouped by category.

## Getting Started

### Dependencies

Run `npm install` to install all dependencies required to run the project

### Running the project

Run `npm run dev` to run the project locally.

## Testing 

Run `npm test` to run tests for the project.

## What I could have done further if time permitted.

- Styling: This could have been a lot better and the layout of the elements for the app especially on desktop.
- CSS framework: I would have considered using Tailwind CSS as a styling framework for it's utility based classes and used to setup design tokens for colours and px values for spacings instead of hardcoded values.
- Accessibility - I could have looked into making the app more accessible for users.
- Refactoring of code - Some of testing logic could be more streamlined and where I have initialised the resources JSON data when the app loads.
- State Management - If this was a larger app I would have considered using Context or Redux.
- Component Library - I could have set up a component library in Storybook for the components used and isolated them for testing and then import them into the project.
